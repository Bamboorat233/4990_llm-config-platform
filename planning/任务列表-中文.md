## M2.5 — 11/28(六) 线上进度检查

- [ ] 生成内容包含:全部 import、超参注入、数据加载、LoRA/SFT 设置(训练)、生成与判定提取(推理)
- [ ] 额外生成 `requirements.txt`(里程碑原文要求「add all the necessary libraries and dependencies」)
- [ ] 与参考脚本逐段对照:参数一致性(自动化对比脚本)+ 语法校验(`ast.parse` / `py_compile`)
- [ ] 修补已知坑(生成器不得照抄参考脚本)
  - [ ] 运算符优先级 bug:`"...Answer: " + doc[0] if doc else ...`(`top_k_doc` 为空时连 Question 都不拼接)
  - [ ] `pad_token = "<myPadToken>"` 非法字面量 → Mistral 用 `<pad>`(id 11)或 `</s>`;DeepSeek 保持 EOS
  - [ ] `fix_mistral_regex` 必须作为 `from_pretrained()` 参数传入,事后赋值无效
  - [ ] 微调集与验证集 assistant 前缀不一致(验证集漏了 `Verdict: `)
  - [ ] 路径一律由配置注入,禁止硬编码
  - [ ] `seed` 必须写入配置(参考脚本缺失,影响可复现性)
